# Enterprise baseline dependency audit triage

Read-only triage checked 2026-10-15 from ignored `tooling/reports/enterprise-baseline/npm-audit.json`, `package.json`, `package-lock.json` (lockfile v3), `npm explain`, and `npm ls --omit=dev`. Baseline reports 28 findings: 5 critical, 15 high, 8 moderate. `git diff -- package.json package-lock.json` was empty; no dependency edits are part of the current working diff. These findings are inherited baseline, not introduced by this PR. This is not a production-readiness determination.

## Reachability

- **Server request path:** `compression@1.8.1` is a direct production dependency (High; fix 1.8.2). `express@5.2.1` resolves vulnerable `proxy-addr@2.0.7` (Critical; fixed 2.0.8). Both are active server middleware/dependency paths. Apply focused patch-level updates and verify response compression, proxy trust configuration, and IP/rate-limit behavior.
- **Client navigation:** `react-router-dom@6.30.6` / `react-router@6.30.6` are production dependencies. Two advisories have fixed version 7.18.0; npm's suggested 7.18.4 is a major-version migration. The SSR constructor issue is specifically limited by the advisory to Framework/Data Mode with manual SSR/hydration; this repo is a Vite SPA. The backslash open-redirect advisory concerns navigation paths and still merits upgrade/route tests.
- **Tailwind build chain:** `tailwindcss` is a devDependency, but `npm ls --omit=dev` still includes it and vulnerable `chokidar`, `braces`, `fast-glob`, `micromatch`, `postcss-nested`, `postcss-selector-parser`, and `source-map-js` through production `tailwindcss-animate`. These appear build/config-time rather than request-handler paths, but remain in the production install graph. npm proposes Tailwind 4.3.3 (major) to clear several transitive findings; `@tailwindcss/typography`'s suggested 0.5.4 is a downgrade from 0.5.16. Do not apply either blindly. The `braces` advisory currently lists no patched 3.x version.
- **Dev/test only:** `concurrently`/`shell-quote`, Vite/esbuild, Vitest/@vitest/mocker/tinypool, TypeScript-ESLint, and their remaining lint/test-only paths are devDependencies. Critical findings in these packages affect local/CI tooling when invoked, not the shipped request path; remediate before exposing dev servers or running untrusted tests/build inputs.

## Minimal safe upgrade groups

1. **Server dependency patches:** `compression` to 1.8.2; `proxy-addr` to 2.0.8 through a compatible Express dependency update or a narrowly scoped, tested override. Re-run server auth, proxy/rate-limit and streaming/compression checks.
2. **Router migration:** move React Router to at least 7.18.0 (audit suggests 7.18.4); update `react-router` and `react-router-dom` together. Test route matching, protected routes, deep links, `Link`/`navigate` external-path handling, and build output.
3. **Build/test toolchain:** Vite patched branch floor 6.4.3, Vitest/@vitest/mocker 4.1.11, esbuild 0.25.0, and tinypool 2.1.2. These are advisory patched versions; npm's offered Vite 8.3.4/Vitest 5.0.4 are broader majors. Upgrade as a coordinated group with the Vite React plugin and run full build plus the complete Vitest suite. Check Windows dev-server exposure/UNC handling.
4. **Tailwind and lint chains:** handle Tailwind 4 migration and typography separately after compatibility review; audit suggests Tailwind 4.3.3 and typography 0.5.4, with the latter a downgrade, not an accepted fix. It also suggests `lovable-tagger` 1.0.20 from current 1.1.13; validate that apparent downgrade before acting. Update TypeScript-ESLint and `concurrently` only to compatible releases that resolve their inherited advisories; report `fixAvailable: true` has no exact target version, so re-resolve through official metadata during that change.

Additional transitive patched floors from the reviewed advisories: `brace-expansion` 1.1.21 or 2.1.7 for the affected installed branches; `source-map-js` 1.2.2; `shell-quote` 1.11.0; `postcss-selector-parser` 7.1.6. The `braces` advisory reports no patched version for 3.0.3. Test compatibility before overrides because the current consumers request older major ranges.
