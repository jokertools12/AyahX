# AyahX domain rules

- Ayah: Quran verse; exact text, diacritics and verse numbering matter.
- Alignment: evidence-backed correspondence between audio and Quran words.
  LLM timestamps alone are untrusted.
- Render job: persistent queued video work with terminal state and an actual
  inspectable output artifact. Queue acceptance does not mean completion.
- Provider: explicitly selected backend for AI requests. Provider changes and
  private upload sharing require the applicable user consent.
- Live acceptance: verified deployed behavior, current assets, worker logs and
  real media output. Health/build success alone is insufficient.
