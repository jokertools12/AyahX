# A2a — واجهات مكتبة البيانات

بُنيت بعد مكتبة المكونات وأساس A1 والـ shell، على خدمات `/api/admin/catalog`؛ لا تستعيد أدمن commit القديم ولا تغيّر الواجهة العامة أو الريندر.

| الصفحة | المكونات والإجراءات المتصلة |
|---|---|
| `/admin/reciters` | بحث وفلاتر من التلاوات الحية، جدول/بطاقات، ظهور تفاؤلي مع تراجع، ترتيب بالسحب/أعلى/أسفل وUndo، معاينة drawer وإخفاء جماعي مع عدد المتأثرين |
| `/admin/reciters/:id` | ملف وأسماء/بلد/نبذة/رابط صورة يتحقق منه الخادم، slug للقراءة، تلاوات/مصفوفة/روابط/تدقيق، دمج بخريطة صريحة وتأكّد مكتوب وأثر إعادة تحقق الصوت |
| `/admin/recitations` | أسماء عربية/إنجليزية inline، افتراضية/ظهور/نقل مؤكّد، ملاحظات، دليل الصوت وoffset، مهام محفوظة لفحص الروابط وحساب الإتاحة مع تقدم وتحديث دوري |
| `/admin/availability` | 114 خلية تستعمل مكونات المكتبة وتنقل الأسهم/Home/End، حالات الإتاحة ومفقود الكلمات والنطاقات، drawer الصوت ورابط عارض التوقيت |
| `/admin/providers` | الحالة والشروط والـ allowlist ودليل المضيفين وإحصاء الروابط والمعدل، تغيير الترخيص للمدير الأعلى مع الصلاحية والملاحظة والدليل والتأكيد المكتوب |
| `/admin/quran` | سور وآيات وكلمات قانونية للقراءة، بصمة قانونية متوقعة/مخزنة، إصدارات، ستة خطوط معتمدة تُحمّل من ملفاتها فعليًا؛ فشل الملف ظاهر ولا يُعرض النص بخط بديل، روايات مع تفعيل مؤكّد |
| `/admin/timings` | اختيار تلاوة/سورة/آية عبر URL، SVG لإحداثيات المصدر نفسها، ربط الكلمات القانونية والتكرار، أسباب النقص والمدققات وJSON؛ لا محرر |

حدود مقصودة: لا Publish يدوي، ولا اعتماد صوت، ولا رفع صور/صوت، ولا إضافة مصادر، ولا محرر توقيت أو أي إجراء A2b/D5. صيغ النص تعرض كنص React عادي، والمعرّفات والروابط والتوقيتات LTR. إعادة الترتيب ترسل IDs المرئية فقط؛ الخادم يحافظ على مواقع الصفوف الأخرى. الفلاتر لا تثبت أعداد القراء أو التلاوات أو الروايات.

التحقق في worktree: `tsc --noEmit` ناجح؛ ESLint للمجلد صفر أخطاء/تحذيرات؛ 14 اختبار وحدة ناجح (نطاق الرسم والتكرار، أدلة الكلمات الناقصة، رفض روابط خطوط غير آمنة، إعادة ترتيب بلا فقد IDs). `tsc -p tsconfig.app.json` كشف أخطاء قديمة في D4/A1؛ أخطاء الاستدلال المحلية عولجت. لا تدّعي هذه الاختبارات قبولًا بصريًا أو اختبار قاعدة حقيقية. فحص Chromium وE2E/axe/Lighthouse والربط الحقيقي وقياس الحزمة ينفذه الجذر على قاعدة MySQL المستعادة قبل الشحن.
