# منصة صانع ريلز القرآن والابتهالات | Quran & Ibtahalat Reel Maker

منصة متكاملة واحترافية لإنتاج وتصميم مقاطع الفيديو والريلز القرآنية والابتهالات الدينية بجودة عالية وبشكل تلقائي، موجهة لصناع المحتوى والقنوات الإسلامية لمشاركتها على TikTok و Instagram Reels و YouTube Shorts.

---

## ✨ المميزات الرئيسية (Key Features)

### 1. استوديو القرآن الكريم (Quran Studio)
- **114 سورة كاملة**: بيانات تفصيلية لجميع السور، نوع النزول (مكية / مدنية)، وعدد الآيات مع بحث فوري.
- **تحديد دقيق لنطاق الآيات**: اختيار مرن من الآية X إلى الآية Y مع التحقق البرمجي التلقائي وضبط الحدود وفق السورة.
- **مكتبة الآيات الشهيرة**: قوالب جاهزة لأشهر الآيات (آية الكرسي، أواخر سورة البقرة، سورة الفاتحة، وغيرها).
- **قائمة كبار القراء**: تلاوات بروايتي حفص وورش (ماهر المعيقلي، مشاري العفاسي، عبد الباسط عبد الصمد، المنشاوي، الحصري، سعد الغامدي، إلخ).
- **المزامنة اللحظية كلمة بكلمة (Word-by-Word Karaoke)**: مزامنة دقيقة مع الصوت عبر Quran Foundation API مع شريط إضاءة تدريجي لكل كلمة.
- **دمج الآيات المتعددة في المتصفح (Audio Concatenation)**: دمج مقاطع الآيات الفردية من سيرفرات EveryAyah دون أي فواصل زمنية عبر Web Audio API.
- **الكشف الذكي عن فترات الصمت (Silence Detection)**: تقسيم الآيات ومحاذاتها تلقائياً في حال غياب التوقيتات من المصدر.

### 2. استوديو الابتهالات والأدعية (Ibtahalat Studio)
- **مكتبة روائع المنشدين**: نصر الدين طوبار، سيد النقشبندي، محمد عمران، وغيرهم مع الحفاظ على وضع الابتهالات (`surah: 0`).
- **القص والتحكم الزمني (Audio Trimming)**: أداة تفاعلية لتحديد بداية ونهاية المقطع المطلوب بدقة عينات الصوت.
- **التفريغ الصوتي التلقائي (AI Transcription)**: دعم تفريغ الصوت وتحويله إلى نصوص متزامنة عبر Google Gemini 1.5 Flash.
- **محرر النصوص والتوقيتات (Timing Editor)**: إمكانية تعديل الكلمات وتوقيت كل سطر بدقة متناهية.

### 3. محرك الرسوم والمؤثرات البصرية (Visual & Canvas Engine)
- **أبعاد متعددة**: ريلز عمودي (9:16) وفيديو أفقي (16:9).
- **مكتبة خلفيات ضخمة**: صور طبيعية، مساجد وزخارف إسلامية، وتدرجات لونية هادئة.
- **فيديوهات Pexels السحابية**: بحث وتنزيل خلفيات فيديو متحركة فائقة الدقة عبر بروكسي الخادم الخلفي المحمي.
- **رفع الخلفيات المخصصة**: دعم رفع الصور والفيديوهات الخاصة مع إدارة ذكية للذاكرة وإلغاء كائنات `Blob`.
- **نظام الجزيئات المتحركة (Particle FX)**: نجوم متلألئة، غبار عائم، مطر، وأشعة ضوئية تفاعلية.
- **محلل الصوت المرئي (Audio Visualizer)**: أمواج صوتية ومؤثرات دائرية متفاعلة مع الترددات الصوتية لحظياً.
- **مؤثرات الصوت الآمنة (Audio FX Rack)**: صدى المساجد (Cathedral Reverb)، تضخيم الباس (Bass Boost)، وتعديل نبرة الصوت (Pitch Shift) مع سقف حماية صوتي للصدى لمنع الصفير.

### 4. التصدير والمعالجة المحلية (Client-Side Video Export)
- **تسجيل مباشر عبر MediaRecorder**: بدون أي استهلاك لمعالجات السيرفر.
- **إصلاح حاوية WebM تلقائياً**: معالجة التوقيت الزمني عبر `fix-webm-duration`.
- **التحويل إلى MP4 بواسطة WebAssembly FFmpeg**: تصدير بصيغة MP4 القياسية مباشرة داخل متصفح المستخدم.
- **دقة تصدير متعددة**: 720p HD و 1080p Full HD و 4K Ultra HD بمعدل 30/60 إطاراً بالثانية.

### 5. النظام السحابي وإدارة المستخدمين (MySQL & Backend)
- **قاعدة بيانات علائقية MySQL 8.0+**: 16 جدولاً مترابطاً مع مفاتيح أجنبية متتالية (Cascading Foreign Keys) وفهارس مركبة محسنة.
- **المصادقة وتأمين الجلسات**: تشفير كلمات المرور باستخدام `Bcrypt` (بحد أقصى 72 بايت لمنع DoS)، وتوكنز `JWT` مع تحديد معدل الطلبات.
- **نظام الاشتراكات وحصص الاستخدام اليومي**: عدّادان ذريان مستقلان: محرك المتصفح (المجانية: 5 يومياً، المميزة: غير محدود) والريندر السحابي (المجانية: 1، الشهري: 15، السنوي: 25 يومياً).
- **بوابات الدفع عبر المحافظ الإلكترونية**: فودافون كاش، اتصالات كاش، أورانج كاش، وي باي، وإنستاباي مع لوحة تدقيق للأدمن وتمديد تراكمي للاشتراكات.
- **نظام الأوسمة ولوحة المتصدرين (Gamification & Leaderboard)**: أوسمة افتراضية مع احتساب دقيق للنقاط وتخزين مؤقت TTL (60 ثانية).
- **المراقبة وجاهزية التشغيل (Observability)**: تسجيل منظم للطلبات، ترويسة تتبع `X-Request-Id`، وإيقاف تشغيل آمن وسلس (Graceful Shutdown).

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **الواجهة الأمامية**: React 18, TypeScript, Vite, Tailwind CSS, Radix UI, Framer Motion, TanStack Query.
- **محرك الصوت والفيديو**: Web Audio API, HTML5 Canvas 2D / WebGL, MediaRecorder API, @ffmpeg/ffmpeg (Wasm).
- **الخادم الخلفي**: Node.js 20+, Express 5, `mysql2/promise`, `bcryptjs`, `jsonwebtoken`, `compression`.
- **قاعدة البيانات**: MySQL 8.0+ / MariaDB (InnoDB, `utf8mb4_unicode_ci`).
- **الاختبارات وضمان الجودة**: Vitest (80+ Tests), Testing Library, ESLint, TypeScript Strict Compiler.

## 🚀 التشغيل والتثبيت محلياً (Quickstart Guide)

### 1. المتطلبات المسبقة (Prerequisites)
- **Node.js**: الإصدار 18 أو أحدث (يُوصى بـ v20+ أو v22 LTS).
- **خادم MySQL**: إصدار 8.0 أو أحدث (محلي عبر XAMPP / Laragon / Docker، أو خادم سحابي).
- **Git**: لاستنساخ المستودع.

### 2. تثبيت الحزم (Installation)
```bash
git clone <REPOSITORY_URL>
cd ayah-clip-maker-main
npm install
```

### 3. إعداد متغيرات البيئة (`.env`)
قم بنسخ ملف القالب النظيف `.env.example` إلى `.env`:
```bash
cp .env.example .env
```
قم بتعديل بيانات الاتصال في `.env` لتناسب بيئتك المحلية:
```env
# إعدادات الخادم والشبكة
PORT=3001
NODE_ENV=development
CORS_ORIGIN=http://localhost:8080,http://localhost:5173

# مفتاح التشفير (يجب تغييره في بيئة الإنتاج)
JWT_SECRET=your_super_secret_jwt_key_here

# اتصال قاعدة بيانات MySQL
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=your_local_password
MYSQL_DATABASE=quran_reels

# خدمات الذكاء الاصطناعي (اختياري لتفريغ الصوت عبر Google Gemini)
GEMINI_API_KEY=

# مفتاح Pexels للبحث في خلفيات الفيديو (اختياري - يتم حقنه من السيرفر)
PEXELS_API_KEY=
```

### 4. تهيئة وإنشاء قاعدة البيانات تلقائياً (Database Setup)
يقوم هذا الأمر بإنشاء قاعدة البيانات `quran_reels` وتطبيق المخطط الكامل (16 جدولاً مع الفهارس المحسنة وبذور الإنجازات):
```bash
npm run db:setup
```

### 5. تشغيل المشروع (Running the Application)
لتشغيل الخادم الخلفي وواجهة التطوير معاً في أمر واحد:
```bash
npm run dev:all
```
أو في نافذتين منفصلتين:
```bash
# النافذة 1: الخادم الخلفي (Port 3001)
npm run server

# النافذة 2: واجهة المستخدم (Port 8080)
npm run dev
```

افتح المتصفح على الرابط: **[http://localhost:8080](http://localhost:8080)**

## 📡 دليل واجهات برمجة التطبيقات (REST API Specification)

جميع مسارات الواجهة الخلفية مسبوقة بالبادئة `/api`. تعيد جميع الاستجابات ترويسة التتبع `X-Request-Id` للتشخيص ومراقبة الأداء.

### 1. الصحة والمراقبة (Health & Diagnostics)
- `GET /api/health`: تقرير الصحة الشامل (حالة النظام، مدة التشغيل Uptime، استهلاك الذاكرة RSS/Heap، وحالة اتصال قاعدة البيانات مع قياس زمن الاستجابة).
- `GET /api/health/live`: فحص حيوية العملية (Liveness Probe) لأنظمة Kubernetes / Docker (يعيد `200 OK` `{ status: 'alive' }`).
- `GET /api/health/ready`: فحص جاهزية قاعدة البيانات (Readiness Probe) لاستقبال الزيارات (`200 OK` عند الاتصال أو `503 Service Unavailable` عند الانقطاع).

### 2. المصادقة والحسابات (Authentication)
- `POST /api/auth/register`: إنشاء حساب جديد (`email`, `password`, `displayName`). محمي بمحدد معدل (20 طلب / 15 دقيقة) وحد 72 بايت لكلمة المرور.
- `POST /api/auth/login`: تسجيل الدخول وإصدار توكن JWT (`email`, `password`).
- `GET /api/auth/me`: جلب بيانات المستخدم الحالي المصادق عليه مع الصلاحيات ورقم الحساب.
- `PUT /api/auth/profile`: تحديث الاسم والنبذة التعريفية ورابط الصورة الرمزية (مع تعقيم لعناوين `javascript:`).

### 3. استوديو الفيديوهات (Videos)
- `GET /api/videos`: تصفح مكتبة الفيديوهات العامة مع ترقيم محكم (`limit` بحد أقصى 100، `page`).
- `GET /api/videos/my`: استرجاع فيديوهات المستخدم الخاصة والعامة (يتطلب مصادقة).
- `GET /api/videos/:id`: تفاصيل مقطع فيديو محدد (مع فحص صلاحية الوصول إذا كان المقطع خاصاً).
- `POST /api/videos`: حفظ مقطع فيديو مكتمل في المكتبة؛ تُحجز حصة Browser Canvas عند بدء التصدير، لا عند حفظ النتيجة، حتى لا يُحسب الفيديو مرتين.
- `POST /api/videos/:id/like`: تبديل الإعجاب بالفيديو (Idempotent Toggle).
- `GET /api/videos/:id/comments`: استرجاع تعليقات الفيديو بترتيب زمني مع دعم الردود المتسلسلة.
- `POST /api/videos/:id/comments`: إضافة تعليق أو رد مع التحقق من وجود الفيديو وحد 1000 حرف.
- `DELETE /api/videos/:id/comments/:commentId`: حذف تعليق مع التحقق من ملكية التعليق أو ملكية الفيديو أو صلاحية الأدمن.

### 4. الملفات الشخصية والتفاعل (Users & Social)
- `GET /api/users/:id/profile`: استرجاع الملف الشخصي لمستخدم (مع حجب البريد الإلكتروني PII لغير أصحاب الحساب).
- `POST /api/users/:id/follow`: متابعة أو إلغاء متابعة مستخدم مع منع تكرار الإشعارات غير المقروءة.
- `GET /api/users/me/favorites`: استرجاع مفضلات المستخدم (السور، القراء، المنشدون).
- `POST /api/users/me/favorites/surah/toggle`: تبديل سورة في المفضلة.
- `POST /api/users/me/favorites/reciter/toggle`: تبديل قارئ في المفضلة.
- `POST /api/users/me/favorites/performer/toggle`: تبديل مبتهل في المفضلة.
- `GET /api/social/feed`: خلاصة الفيديوهات للمستخدمين المتابعين عبر استعلامات ربط علائقية سريعة.

### 5. الاشتراكات والمدفوعات (Subscriptions)
- `GET /api/subscriptions/plans`: خطط الاشتراك المتاحة ومميزات كل باقة.
- `GET /api/subscriptions/my-subscription`: تفاصيل الاشتراك الحالي وحالته وتاريخ الانتهاء.
- `GET /api/subscriptions/usage/today`: عدد الفيديوهات المنتجة اليوم والمتبقي من الحصة.
- `POST /api/subscriptions/request-payment`: إرسال طلب ترقية (`plan`, `amount`, `paymentMethod`, `phoneNumber`). محمي بالتحقق من صحة الرقم والمبلغ ومنع تكرار الطلبات المعلقة.

### 6. الإنجازات والصدارة (Achievements)
- `GET /api/achievements`: قائمة الإنجازات العشرة وحالة فك كل إنجاز للمستخدم.
- `POST /api/achievements/unlock`: فك إنجاز مع التحقق من شروط الاستحقاق في قاعدة البيانات ومعالجة ذرية لحالات السباق.
- `GET /api/achievements/leaderboard`: ترتيب المتصدرين مع كاش ذاكرة (60 ثانية) وإلغاء فوري عند فك إنجاز جديد.

### 7. الخدمات والذكاء الاصطناعي (Services)
- `GET /api/services/video-proxy?url=`: تمرير مباشر لتدفقات الفيديو الخارجية مع إلغاء التدفق عند انقطاع اتصال العميل (`AbortController`).
- `POST /api/services/transcribe-audio`: تفريغ صوتي آمن محمي بالمصادقة وتحديد النطاقات وحجم 25 ميجابايت كحد أقصى.
- `POST /api/services/refine-text`: ضبط وتشكيل النصوص العربية بالذكاء الاصطناعي (Gemini / Lovable).
- `POST /api/services/refine-timing`: ضبط وتعديل فواصل الكلمات ومزامنتها.
- `GET /api/services/pexels/search`: بحث في فيديوهات Pexels مع كاش ذاكرة لمدة 15 دقيقة وإخفاء المفتاح عن الواجهة.
- `GET /api/services/pexels/popular`: استعراض مقاطع Pexels الشائعة.

## 🛡️ الأمان والجاهزية التشغيلية (Security & Operability)

1. **إيقاف التشغيل الآمن (Graceful Shutdown)**:
   - يستمع الخادم لإشارات `SIGINT` و `SIGTERM`.
   - عند الاستلام، يتوقف السيرفر عن استقبال طلبات جديدة (مع إرجاع HTTP 503 للطلبات الواردة أثناء الإغلاق).
   - يمنح الطلبات الجارية مهلة تصل إلى 10 ثوانٍ لإنهاء معالجتها.
   - يقوم بتصريف وإغلاق مجمع اتصالات قاعدة البيانات (`closePool()`) بأمان تام لمنع تسريب الاتصالات.

2. **التسجيل المنظم والتتبع (Structured Logging & Tracing)**:
   - توليد أو تمرير ترويسة `X-Request-Id` عبر وسيط `requestLogger`.
   - تسجيل المسار، طريقة HTTP، كود الاستجابة، وزمن المعالجة بالملي ثانية.
   - إتاحة خطاف خطأ مركزي `registerErrorHook` لربط أدوات التتبع السحابية (Sentry / Datadog / PostHog).

3. **أمان بيئة الإنتاج (Production Guards)**:
   - رفض تشغيل الخادم في بيئة الإنتاج (`NODE_ENV === 'production'`) إذا كان `JWT_SECRET` غير محدد أو مطابقاً للمفتاح الافتراضي.
   - حجب عناوين الشبكات الداخلية والخدمات السحابية الوصفية (`169.254.169.254`) لمنع هجمات SSRF.
   - تفعيل ترويسات OWASP: `nosniff`, `SAMEORIGIN`, `HSTS`, وتعطيل `x-powered-by`.
