## ما تغيّر

أضيف مسار RenderManifest `2.0.0` خادمي بجانب v1. الطلب يقبل فقط `recitationId/surah/from/to/options/qa:true`؛ الروابط والتوقيتات وAudioPlan لا تأتي من العميل. البناء يقرأ النص القانوني والتوقيتات والمصدر الفعلي، ويرفض النطاق الناقص مع `available_runs` وYouTube بلا ملف مرخّص. أداة `/api/admin/render-lab/jobs` محمية بـ `render.test` ودور admin أو super_admin، وOrigin/rate/audit، بمدة قصوى 90 ثانية وتزامن عالمي واحد. لا واجهة عامة جديدة، والعلم الإنتاجي مغلق.

التحويل الزمني الوحيد `shared/timing/toRenderTimeline.ts`؛ الأزمنة الصحيحة بالمللي ثانية، pad لا يزيد عن150ms. تظليل الكلمة يتبع أول interval فعلي، مع hold للوقف حتى250ms وربط التكرار بالكلمات القانونية. needs_review وestimated وفشل الربط تعرض تظليل الآية فقط. حساب عدد إطارات v2 هو `ceil(duration × fps)`؛ v1 يحتفظ بسلوكه السابق ويحتاج قبولًا فعليًا قبل/بعد النشر.

migration007 توسّع `render_jobs` بثمانية أعمدة nullable فقط: `recitation_id VARCHAR(36)` و`audio_plan_hash CHAR(64)` و`timing_version_hash CHAR(64)` و`audio_mode_used VARCHAR(32)` و`fallback_used BOOLEAN` و`audio_bytes_fetched BIGINT UNSIGNED` و`audio_provider_code VARCHAR(64)` و`qa_report_json JSON`. الأعمدة النصية `utf8mb4_unicode_ci`. تضيف تعريف `render.test` عالميًا؛ منح الدورين خطوة صريحة منفصلة بعد SUCCESS للنسخ الجديدة، لأن كود الأدمن القديم يرفض الصلاحية غير المعروفة. لا seed عند startup ولا تغيير user_roles أو الحسابات.
