# مقارنة عناصر الموقع والأدمن

هذه أزواج من لقطات المتصفح الفعلية للموقع القائم وواجهة الأدمن، وليست صورًا مولّدة. صدّر الوكيل الرئيسي مقتطفات وصورًا مصغرة من التشغيل المحلي؛ [فهرس الأدلة](../admin-pages/index.json) يسجل مصادرها والبصمات والتحجيم والاقتصاص. لقطات الأدمن من التشغيل المحمّل `01a12acc-d26e-7183-a414-318fbd9cd5f5`، بعد انتظار الخطوط والبيانات الفعلية. صور UI Kit تعرض المكونات وحالاتها صراحةً؛ بيانات الاختبار المحلية ليست بيانات إنتاج.

| العنصر | الموقع القائم | الأدمن | الهوية المشتركة والفارق المقصود |
|---|---|---|---|
| زر | [زر الموقع](button-public.png) | [زر الأدمن](button-admin.png) | يعيد استخدام اللون الأساسي والخط والحواف. الأدمن يضيف حالات وإجراءات قصيرة مناسبة للأدوات؛ لا هوية لونية جديدة |
| بطاقة | [بطاقة الموقع](card-public.png) | [بطاقة الأدمن](card-admin.png) | سطح وحدود مستمدة من tokens القائمة؛ بطاقة الأدمن أشد كثافة للقياسات والمعلومات التشغيلية |
| حقل | [حقل الموقع](field-public.png) | [حقل الأدمن](field-admin.png) | خط Cairo والحدود والخلفية الدلالية نفسها؛ label وحالات التعطيل والتحقق تبقى ظاهرة في الأدمن |
| نموذج | [نموذج الموقع](form-public.png) | [نموذج الأدمن](form-admin.png) | العام نموذج دخول موجه لغرض واحد؛ UI Kit الإداري يعرض أنواع حقول ورسائل تحقق متعددة داخل شبكة كثيفة، مع RTL |
| مجموعة بيانات | [بطاقات السور العامة](table-public.png) | [جدول التلاوات الإداري](table-admin.png) | **الموقع العام يعرض بطاقات، وليس جدولًا مماثلًا**. الجدول الإداري يضيف أعمدة حالة وتحديدًا وإجراءات للعمليات؛ يحتفظ بالخط والأسطح والحدود، ويتحول إلى بطاقات على الهاتف |
| شارة | [شارة الموقع](chip-public.png) | [شارة الأدمن](chip-admin.png) | أشكال وألوان دلالية من الهوية الحالية؛ شارة الأدمن تجمع نصًا وأيقونة مع اللون حتى لا تصبح الحالة معلومة لونية فقط |

المقارنة تثبت إعادة استخدام الهوية مع تغيير كثافة العرض بحسب الغرض؛ لا تقيس وحدها التباين أو صلاحية كل إجراء. نتائج axe والوظائف وLighthouse وحدود الإنتاج موثقة في [مراجعة الواجهة](../../admin-ui-review.md). فحص الصفحات النهائي شمل 56 حالة عربية (14 صفحة × جهازين × مظهرين)، بصفر مخالفات حرجة أو خطيرة، والقبول الوظيفي المحلي النهائي 18/18. لا تشمل الصور أسرار الدخول أو TOTP أو رموز الاسترداد.
