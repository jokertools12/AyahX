# K5 — تقدير R2 وحالة القدرة الفعلية، 2026-10-10

قرأت [توثيق تسعير Cloudflare R2 الرسمي](https://developers.cloudflare.com/r2/pricing/) مباشرة في هذه الجلسة؛ الصفحة محدّثة 2026-10-01. أسعار Standard المنشورة: 0.015$/GB-month، و4.50$/مليون Class A، و0.36$/مليون Class B؛ والحصة الشهرية المجانية 10GB-month ومليون A وعشرة ملايين B. تُقرب الوحدات المدفوعة لأعلى. التخزين الشهري يعتمد متوسط ذروة كل يوم خلال دورة ثلاثين يومًا، وليس قراءة الحجم الحالية وحدها. تلك الحصة تخص Standard فقط. [المصدر](https://developers.cloudflare.com/r2/pricing/)

صححت `estimateAudioStorageCost`: بعد طرح الحصة المدخلة، `ceil(excess / unit)` مستقل لكل فئة، مع `billableUnits` ظاهرة للمراجع وتنبيهات مبنية على المجموع المقرب. مثال تجاوز التخزين المجاني ببايت واحد يكلف وحدة GB-month واحدة، وتجاوز A المجاني بعملية واحدة يكلف مليونًا مدفوعًا واحدًا. بقيت الأسعار مدخلات مسجلة بالمصدر والتاريخ، ولم تصبح ثوابت تشغيل. الـbytes في العقد يمثل متوسط الذروة الشهري المتوقع أو افتراض بقاء ذلك الحجم شهرًا؛ والعمليات والحصة تُقاسان على الحساب ككل، دون تكرار المجاني لكل bucket. لا يشمل النموذج Infrequent Access أو خدمات أخرى أو ضرائب، ولا يقرأ فاتورة حساب فعلية.

الاختبارات: 22 حدًا لتقدير الفوترة، تشمل قبل/عند/بعد المجاني، الحد المدفوع التالي، جمع الفئات والتنبيهات والمدخلات غير الصالحة. للمشغّل الأسبوعي 16 حالة بعد إضافة إغلاق عميل read-only المملوك لكل تشغيل في finally، ورفض مفتاح لا يطابق surah/SHA للصف. المجموعة مع وحدات الصوت المرخص 65/65 ناجحة، وstrict TypeScript وlint للملفات الأربعة بلا رسائل. لم أعدل `catalogRuntime.ts` أو `server/index.ts` أو إعداد التخزين؛ الجذر يملك ربط التشغيل. `storageProvider` يسلّم عميلًا جديدًا مملوكًا للتشغيل، لا عميلًا مشتركًا تستخدمه مسارات أخرى؛ `close?` يغلقه عند النجاح والفشل وعدم حلول الأسبوع. `url_reference` يبقى خاملًا دون إنشاء عميل أو قراءة credentials.

القدرة السحابية الحية ما زالت غير متاحة لهذه المهمة: أدوات Cloudflare أُزيلت من الجلسة، ولا تفعيل أو tokens مثبتة؛ آخر قراءة سابقة عند الجذر كانت buckets فارغة. لم تُتحقق فاتورة R2 أو حصة الحساب المتبقية أو تكلفة فعلية. بقي التفعيل خارج العمل، ولا نجاح R2 أو S3 حي يُدعى. لم أعد محاولة بدء S3 المحلي المحظور ولم أحذف ملفات أو أغير صلاحيات أو أكتب DB/cloud. اختبارات SDK وDB وحدات فقط؛ دليل ملف JSON الخاص دليل filesystem للmetadata، لا دليل قبول خدمة تخزين سحابية.
