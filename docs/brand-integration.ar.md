# تطبيق هوية AyahX

تم استيراد الهوية من AyahX Brand Studio، النسخة الأصلية ذات commit
`1e2fc866352ea96cdda4eb3ea1c9db0a9c77b770`، وتطبيقها في مشروع AyahX المحلي.
لم نغيّر موقع Brand Studio أو خصوصيته، ولم ننشر المشروع على Railway ضمن هذا العمل.

## الأصول

`public/brand/` يحتوي الشعار الأفقي والرأسي، الرمز، أيقونة التطبيق، favicon،
والنسخ الأحادية السوداء والبيضاء. نُقلت 14 نسخة SVG/PNG/ICO مطابقة لملفات
مصدر Brand Studio. SVG يحافظ على وضوح الشعار مع مختلف أحجام الشاشات.
بصمات المصدر مسجلة في `public/brand/provenance.json`.

الألوان الأساسية هي Emerald `#056B4B` وGold `#D2A536` وMidnight `#0D2C46`.
تم توحيد ألوان المكونات المشتركة من خلال CSS tokens، مع درجات فاتحة للزمردي
ونصوص واضحة في الوضع الداكن. خطوط القرآن وخيارات المستخدم في محرر الفيديو
لم يتم استبدالها بخط الشعار؛ ملفات الشعار نفسها تحتوي مسارات vector للكلمات.

`BrandLogo` يختار الشعار الملون في الوضع الفاتح والأبيض في الداكن. النسخة
الرأسية في شاشة الدخول توضع على مساحة بيضاء لحفظ ألوانها الأصلية ووضوحها.
الاسم في العناوين والمشاركة والسياسات أصبح AyahX.

## مواضع الاستخدام

- شريط التنقل والتذييل: الشعار الأفقي في جميع الصفحات التي تستخدم Layout.
- الرئيسية: هوية واضحة قبل العنوان، ونسخة بيضاء في دعوة الإنشاء.
- الدخول: الشعار الرأسي الأصلي؛ نماذج الدخول والتسجيل والاستعادة كما هي.
- التحميل وصفحة 404 وحالة الخطأ العامة: علامة التطبيق والشعار حسب السياق.
- المتصفح: favicon SVG وICO؛ أيقونة Apple Touch وأيقونات 192 و512.
- المشاركة: صورة 1200×630 مشتقة من الشعار الأصلي، وعناوين Open Graph وTwitter.
- إعدادات الفيديو: اختيار الشعار الملون أو الأبيض أو الرمز كعلامة مائية.

## العلامة المائية

في إعدادات العرض، فعّل الشعار ثم اختر إحدى نسخ AyahX. تظل صلاحية
`customBranding` الحالية مطلوبة؛ لم يتم تجاوز قواعد الاشتراك.
اختيار الشعار لا يتصل بمزوّد AI ولا يرفع ملفات. تُقرأ صورة PNG محلية ثم
تُضمّن bytes كـdata URL بنفس طريقة الشعار المخصص الموجودة؛ هذا يتيح للمحرر
والرندر السحابي تلقي نفس الأصل دون الاعتماد على رابط موقع Brand Studio الخاص.
الاختيار يدوي ويمكن إلغاؤه، ولا يغيّر المقاطع أو القوالب المحفوظة تلقائيًا.

## أوامر إعادة التصدير والفحص

```powershell
node scripts/export-brand-assets.mjs
npm run build
npm test -- src/test/brandAssets.test.ts src/test/brandWatermark.test.ts src/test/brandNativeRender.test.ts src/test/brandingImageReady.test.ts

# شغّل npm run dev أولًا، ثم:
node scripts/qa-brand.mjs
```

أيقونات التطبيق وصورة المشاركة مشتقة محليًا من SVG الأصلي، وليست بدائل
مولّدة بالذكاء الاصطناعي. ملف manifest يعرّف الاسم والأيقونات فقط؛ لا يضيف
service worker ولا يدّعي توفر التطبيق دون اتصال.

الفحص المرئي المحلي وتقرير المتصفح وصور المعاينة داخل `qa-output/brand/`.
فحص الرندر ينتج إطارات أصلية 720×1280 للنسخ الثلاثة. هذه أدلة تحميل ورسم
الأصول؛ لا تعادل اختبار فيديو نهائي بالصوت على Railway أو اختبار حساب مدفوع.
خدمات الخلفية وتسجيل الدخول الفعلي والنشر خارج نطاق هذه المعاينة المحلية.

## نتائج التحقق في 7 أكتوبر 2026

- بناء Vite والخادم ناجح بعد آخر تغييرات المصدر والأصول.
- 13 اختبارًا ناجحًا: 7 خاصة بتكامل البراند وأصوله و3 إطاراته الأصلية،
  و6 اختبارات موجودة مسبقًا لقبول أنماط الشعارات وتجهيز الصورة للرندر.
- 60 حالة متصفح: الرئيسية والدخول والإنشاء والأسعار والسور و404، على
  320 و390 و768 و1024 و1440 بكسل، في الفاتح والداكن.
- الأصول الظاهرة محمّلة، لا توجد أخطاء JavaScript غير معالجة أو overflow
  أفقي بالصفحات المختبرة؛ العربية RTL والشعار المناسب لكل وضع موجودان.
- القائمة المتنقلة والانتقال للإنشاء وتبويب التسجيل وتبديل الوضع تعمل.
- تمت مراجعة صور الواجهة وصورة المشاركة العربية وإطار رندر أصلي بصريًا.
