# إعادة تنظيم الواجهة مع الحفاظ على الوظائف

Baseline: `66c73c004d09ad0f07215265c0b44c7956eaf2cd`.

## حدود العمل

تغييرات العرض والتنقل والنصوص الموجهة للمستخدم فقط. لا تغيير للخادم أو العقود أو الصلاحيات أو البيانات أو معالجات الأحداث أو قيم الخيارات. لا نشر تلقائي ضمن هذه المهمة الجديدة قبل استكمال التحقق. تبقى الهوية العربية والألوان والخطوط الحالية.

`baseline-inventory.json` جرد قبل التعديل لجميع ملفات TSX في src: عناصر التحكم، النصوص، خصائص الربط، شروط العرض، تعريفات الحالة والاعتماديات. يضم عناصر مشتركة ومكررة؛ العدد ليس عدد الوظائف. لا يكفي الجرد الآلي وحده لإثبات الوصول أو صحة السلوك. يلزم فحص المكونات والخيارات المولدة من البيانات واختبار التفاعل.

## نصوص المستخدم

- إزالة تسميات «فكرة 1 / 2 / 3» من أسماء المحركات مع الحفاظ على الاختيارات الأربعة والقيم الداخلية.
- وصف المحركات بأسماء ثابتة مفهومة، دون وعود أداء غير مثبتة أو تعليمات تطوير.
- استبدال تفاصيل «وضع مراجعة التوقيت» و«تشغيل متصل بدون تقطيع» بوصف موجز أمين لحالة الصوت والتزامن. لا تغيير لشروط اعتماد التوقيت.
- الحفاظ على رسائل الخطأ القابلة للتصرف، والتنبيهات المتعلقة بفشل الصوت أو التصدير أو الصلاحيات.
- لا إزالة معلومات تقنية يحتاجها المسؤول داخل الإدارة.

## ضوابط حفظ الحالة

- استخدام إظهار/إخفاء يحافظ على تركيب المكونات حين توجد حالة محلية أو حقول غير متحكم بها.
- عدم تغيير مفاتيح React، القيم الافتراضية، query parameters، localStorage، handlers، شروط disabled أو شروط العضوية.
- عدم تكرار مكونات رفع الملفات أو الصوت أو النماذج في نسختين للهاتف والحاسوب.
- زر فتح المجموعة لا يرسل نموذجًا؛ التركيز ولوحة المفاتيح وحالة aria-expanded مطلوبة.
- لا CSS عام يخفي عناصر حسب ترتيبها أو نصها. التجميع صريح في JSX.

## سجل التنفيذ والتحقق

السجل أدناه تاريخي. حالة التسليم الحالية وأدلة الاكتمال وحدود التحقق في `verification.md`؛ انتهى التشغيل النهائي الموحد إلى 263/263 اختبارًا ناجحًا. التسليم محلي بلا نشر.

- أضيف `SettingsSection` باستخدام details/summary؛ يبقى المحتوى مركبًا عند الإغلاق.
- المعاينة: نقل أزرار التشغيل الأربعة وشريط التقدم خارج تبويبات الإعدادات؛ بقيت معالجاتها وشروط تعطيلها كما كانت. التبويبات الستة داخل إعدادات الفيديو، وأصبح عنوان تبويب التحكم «قص المقطع» لأن التشغيل ظاهر خارجه.
- تجميع أدوات الكلمات والتوقيت دون تعديل إجراءات التحرير أو الاستعادة أو التحسين.
- التصدير: تجميع معدل الإطارات والصوت، وطرق الإنتاج والتسجيل؛ الحفاظ على المحركات الأربعة والصيغ والقيم والقيود.
- Navbar: الروابط الثلاثة الثانوية في المزيد، وإظهار قائمة الهاتف حتى breakpoint xl لتجنب ازدحام الأجهزة المتوسطة. كل الوجهات وشروط المستخدم والإدارة باقية.
- Browse: تجميع التصنيفات. Create: تجميع إعدادات النص. Library: تجميع إجراءات الفيديو. UserSettings: تجميع تغيير كلمة المرور والاستخدام وحذف الحساب.
- تبسيط أسماء المحركات ونصوص حالة التوقيت دون تغيير الشروط أو النتائج.
- `node scripts/verify-ui-preservation.mjs`: نجاح مقارنة 562 ارتباطًا أصليًا (handlers والقيم وشروط disabled ووجهات الروابط وغيرها). هذا فحص ثابت ولا يثبت وحده جميع حالات التشغيل.
- `npx tsc --noEmit`: عاد بنجاح لكنه لا يفحص المشروع المشار إليه لأن tsconfig الجذر يحتوي files فارغة. لا يُعتمد عليه كإثبات سلامة الأنواع؛ انظر نتيجة الفحص الصريح أدناه.
- `npm run build`: ناجح.
- `npx vitest run src/test/settingsSection.test.tsx --reporter=dot`: اختباران ناجحان؛ بقاء الإدخال المتحكم وغير المتحكم به عند الإغلاق وإعادة التصيير، وعدم إرسال النموذج عند فتح القسم.
- فحص متصفح محلي `/browse`: جميع خيارات التصفية متاحة؛ اختيار مدنية يعرض 28 سورة، والعدد يبقى 28 بعد إغلاق القسم. تمت مراجعة لقطة الحاسوب في الوضع الداكن.

الحالة: تنفيذ أولي محلي؛ لم يُنشر. يلزم استكمال خريطة عنصر-بعنصر، ومراجعة بقية التجمعات، والاختبارات عبر أحجام الشاشات وحالات العضوية والتصدير. خادم Vite المحلي بدأ على 127.0.0.1:8080 (جلسة 89432؛ يجب التحقق من بقائه حيًا قبل الاعتماد عليه).

### متابعة التحقق

- `element-map.json` يربط 883 موضع JSX أصليًا بمواقعها الحالية، مع ربط الأحداث والقيم وشروط العرض الأصلية والمجموعات الجديدة. المطابقة تستهلك كل تكرار مرة واحدة، ولا توجد عناصر غير مرتبطة. هذه خريطة مصدرية تشمل المكونات المشتركة وليست ادعاء اختبار 883 وظيفة مستقلة.
- اختبارات الإعدادات والتصدير والتنقل: 12/12. تشمل الزائر والمستخدم والمسؤول، المحركات الأربعة، استراتيجيات التسجيل الأربع، العضوية المجانية والمميزة، نفاد الحصة، معدل الإطارات والصوت، حالات توفر التحميل، وحفظ الاختيارات عند الطي.
- فحص متصفح `/browse`: لا تجاوز أفقي عند 390 و768 و1280 و1440. فحص بصري للهاتف والتابلت والحاسوب. قائمة الهاتف تعرض الوجهات الست، Enter يفتح مجموعة الفلاتر، واختيار مدنية يبقى 28 سورة بعد الطي.
- فحص `/create`: الفاتحة، مشاري العفاسي، الآيات 1–3، الخلفية الافتراضية. رفع حجم الخط من 28 إلى 30 ثم طي المجموعة وفتحها أبقى 30. انتقل المعالج إلى ملخص صحيح ثم المعاينة.
- فحص `/preview`: التشغيل خارج الإعدادات يعمل؛ تقدم إلى 0:11 والآية الثانية من ثلاث، مع بقاء التصدير والإعدادات واضحين. يلزم استكمال فحص الإعدادات الموسعة والأحجام المختلفة لهذه الصفحة.
- تبويبات المعاينة أصبحت ثلاثة أعمدة ثابتة لأن اللوحة نفسها ضيقة حتى على شاشات واسعة.
- كشف `npx tsc --noEmit -p tsconfig.app.json` أخطاء سابقة غير مرئية في أمر الجذر. أصلح استيراد Sparkles وClock3 في صفحة الحساب (كانا مستخدمين بلا استيراد في baseline).
- المستخدم وافق صراحةً على إصلاح خلل تحويل MP4 المكتشف: أصبح convertToMp4 يقرأ fps وaudioBitrate من recordingOutputRef الموجود مسبقًا بدل متغيرات غير معرّفة. اختباران ناجحان بمُحاكاة الخدمات: إرسال 60/320k للخادم، وتمرير 30/128k للتحويل المحلي عند فشل الخادم، وإعادة استخدام الملف المحول. لا يزال اختبار ملف MP4 حقيقي مطلوبًا.
- البناء `npm run build` ناجح بعد الإصلاح. الفحص الصريح للأنواع لا يزال يفشل في nativeSceneRenderer وrenderObservability، ومقارنة image/color في PreviewPage، وfixture قديم في multiEngineSettingsMatrix. لا يُعلن نجاح TypeScript الكامل.
- لم تُغيّر APIs أو الخادم أو البيانات أو صلاحيات الوصول، ولم تُنشر هذه التعديلات.

### فحص الهاتف والتحويل الحقيقي

- أظهر الفحص البصري أن الحشوات المتداخلة تضيق خيارات الإنتاج على الهاتف. خُففت حشوات SettingsSection وExportFormatSelector وأصبحت شارات الحصة قابلة للالتفاف. لقطة الهاتف التالية أظهرت أسماء FFmpeg وSkia وشارات الحصة واضحة دون تكسّر العنوان إلى كلمة في كل سطر.
- تبويبات المعاينة الست فُتحت فعليًا عند عرض 390، وكل منها بلا تجاوز أفقي (عرض الوثيقة 375 مع مساحة scrollbar). اختيار FFmpeg بقي محفوظًا بعد طي إعدادات الفيديو وفتحها. القيود المجانية ظهرت داخل أقسام الصوت والخلفية والقوالب كما كانت.
