# مراجعة مصادر AyahX

هذه الوثيقة تسجل أدلة المراجعة الخارجية ولا تمنح أي مصدر صلاحية تشغيلية وحدها.
تبقى حالة التفعيل مرتبطة بسجل الأدلة في التطبيق، ومطابقة الهوية، وموافقة
الأدمن، وحقوق كل أصل صوتي.

## QUD Universal Audio — v3.2.0

تاريخ المراجعة: 2026-10-16

المراجع الرسمية:

- المستودع: `https://github.com/QUD-Technologies/quranic-universal-audio`
- الإصدار المثبت في AyahX: `https://github.com/QUD-Technologies/quranic-universal-audio/releases/tag/v3.2.0`

الأدلة المرئية في المستودع والإصدار:

- أعمال المشروع الخاصة، مثل التوقيتات والتقسيم وبيانات الفهرس والكود، مذكورة
  تحت CC BY 4.0.
- الإصدار يوفّر `manifest.json` و`catalog.json` وchecksums وملف LICENSE، ولذلك
  يمكن استخدامه كمرجع revision وchecksum بعد حفظ نسخة الخادم المطابقة.
- التسجيلات الصوتية تبقى ملكًا للقارئ أو للمصدر upstream؛ رخصة بيانات QUD لا
  تثبت وحدها حق AyahX في إعادة توزيع أو استضافة كل تسجيل.

قرار AyahX:

- لا تفعيل إنتاجي ولا fallback خارجي.
- يبقى `qud-universal-audio` معطلاً حتى تكتمل أدلة endpoint وlicense وstorage وCORS
  وrate limits وidentity، مع مراجعة منفصلة لحقوق كل تسجيل مستخدم.
- لا تُرفع وسائط خاصة إلى QUD أو Hugging Face، ولا تتحول نتيجة provisional إلى
  canonical أو approved تلقائياً.
