# مراجعة أدمن AyahX — الدفعة الخامسة

تصف هذه الوثيقة النسخة المعاد بناؤها؛ قبولA1/A2a التاريخي لا يثبت قبولها. المرجع السابق للتعديل هو [admin-visual-truth-before.md](data/admin-visual-truth-before.md) وأدلة الإنتاج والمحاكاة المحلية وتطابق الأصول التي سجلها الوكيل الرئيسي.

## ما تغير

أصبحت البداية قائمة مهام فعلية. القائمة عشر مجموعات عربية بأيقوناتLucide والمحتوى كامل العرض. القراءة Cairo15 وسطر1.7 وعناوين28/22/18؛ القائمة درج تحت1100px والجداول بطاقات تحت768px. تفضيلات القراءة محفوظة لكل حساب. بقي الموقع العام والريندر خارج التعديل.

الأدوات: المراجعة ودليلها وتاريخها، الاستماع والمقارنة، تراخيص المزوّدين، الأسماء، التخزين، الصوت المرخص ورفعه، معالج القارئ، الفيديو، الجاهزية، المشروع والدليل. تستخدم عقودًا فعلية دون ملء قرارات المالك. الكتالوج مغلق حتىD8. اكتمال الرفع لا يعني تحقق التوقيت؛ غياب مرجع الإزاحة المستقل يبقى سبب مراجعة.

## التحقق من المصدر والوحدات

يشمل فحصTypeScript المخصص جميع جذورsrc/admin، دون تشخيص داخلي أو خارجي أو عام في التشغيل الأخير أثناء التنفيذ. lint للمتغير بلا تحذير. تمر وحدات القاموس والمراجعة والرفع والاستئناف والبصمة والأدلة والتأكيد؛ يثبت التقرير المتكامل الأوامر والأعداد النهائية.

النوافذ والأدراج لها data-admin-visual-open وdata-admin-visual-dialog، وvisualId للتأكيد وvisualDialogId للفتاحة المشتركة. بعض التأكيدات تحتاج صلاحية أو مدخلات أو مهمة فعلية؛ اختبارها يحتاج تلك الحالة دون أزرار التفاف. المعاينة الجماعية تحتاج طلب المعاينة قبل ظهور التأكيد؛ فحص القراءة لا يكتب قرارًا.

كشف الفحص الأولي حدود أزرار ضعيفة وتلميح شعار مفقودًا وحاجة إلى فصل النص العربي وحدودcheckbox أصلية لا يقيسهاCSS. أضيفت حدود منmuted-foreground وتلميح ومسافة8px ورسم صريح للcheckbox. مراجعةcolor(srgb) وحدودalpha=0 وقياس الحروف في الماسح تحافظ على معايير القبول.

## القبول الحي

لا تدعي هذه النسخة اكتمال القبول الحي. يسجل الوكيل الرئيسي نتائج النسخة النهائية وروابط أدلتها بعد إعادة البناء:

- كل المسارات والنوافذ الممكن فتحها بحالة فعلية، معRTL/EN واللونين والهاتف/سطح المكتب والتكبير الأصلي وما تحت الطية وحاويات التمرير.
- صفر مخالفات خط/تحكم/تباين/قص/تراكب/فجوة وaxe بلا حرجة أو خطيرة؛ غير المحسوم يحتاج دليلًا.
- مهماتM1–M12 بميزانياتها وببيانات وصلاحيات حقيقية. الكتابات التجريبية محلية؛ لا يقرر الاختبار نيابة عن المالك في الإنتاج.
- الرفع والاستئناف والرفض والتحقق وYouTube الرسمي والمسودة والفيديو والجودة والحذف.
- CI والنشرSUCCESS والصحة واللوج والتحقق القرائي والجداول المحمية وفق تفويض الدفعة.

فهرس قبل/بعد والإنتاج والقبول المتكامل فيdocs/data يحدّثه الوكيل الرئيسي بعد التشغيل. لا تحل الوثيقة محل تقرير الدفعة ولا تفتح الكتالوج أوD5/D8.
