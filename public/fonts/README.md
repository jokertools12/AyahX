# Arabic fonts

These fonts are distributed under the SIL Open Font License 1.1. The matching
`*-OFL.txt` files contain each family's license and copyright notice.

Sources: https://github.com/google/fonts/tree/main/ofl (family folders matching
the filenames). Amiri and Noto Naskh Arabic were already bundled with AyahX;
the remaining families come from the same official Google Fonts repository.

The shared browser harness and native renderers load these local files so the
selected family works without an external Google Fonts connection.
