1. قائمة القراء: صورة، الاسم، البلد، عدد التلاوات (عامة/الكل)، أفضل إتاحة (عدد السور المكتملة)، ملخص حالة الصوت، مميّز، ظاهر، ترتيب بالسحب؛ بحث وفلاتر (رواية، أسلوب، مصدر، حالة، إتاحة، حالة تأكيد الصوت) وإجراءات جماعية.
2. صفحة القارئ (تبويبات): (أ) الملف الشخصي؛ (ب) التلاوات/المصادر: جدول لكل تلاوة بالاسم الوصفي القابل للتعديل (ع/إنجليزي)، المزوّد/القناة، الأسلوب، الرواية، السنة، الجودة، مستوى الإتاحة (كم سورة مكتملة/شبه مكتملة/جزئية)، جودة التوقيت، حالة الـ offset (v1/v2/فشل/غير متاح)، حالة تأكيد الصوت، حالة ترخيص المزوّد، الحالة التقنية، مفتاح الظهور العام، اختيار الافتراضي، ترتيب بالسحب، ملاحظات؛ وإجراءات: إخفاء/إظهار، جعلها افتراضية، نقلها لقارئ آخر، فحص الروابط، إضافة رابط بديل؛ (ج) غرفة الاستماع: العيّنات الثلاث لكل تلاوة تُشغَّل من رابط المزوّد بنطاق زمني، ومقارنة جنبًا إلى جنب بين تلاوات القارئ الواحد، وقائمة تحقق (الصوت يطابق القارئ؟ الأسلوب؟ الجودة؟ ضوضاء؟ تكرار؟)، وأزرار تأكيد/عدم تطابق مع ملاحظة، وسجل بالتغييرات؛ (د) مصفوفة الإتاحة: 114 خلية ملوّنة لكل تلاوة (مكتملة/شبه مكتملة مع الكلمات الناقصة/جزئية بنطاقاتها/غير متاحة/بلا صوت) مع تفاصيل عند النقر ورابط لمحرر التوقيت؛ (هـ) روابط الصوت وصحتها (HEAD/Range) وآخر فحص والفشل؛ (و) سجل التدقيق.
3. صفحة المزوّدين: الحالة، شروط الاستخدام (رابط الملخص)، license_status، قائمة المضيفين المسموحة، صحة الروابط.
4. معالج «إضافة تلاوة/مصدر جديد» دون كود: اختيار المحوّل، إدخال بيانات الكتالوج أو نمط الرابط، اختبار الروابط، استيراد التوقيتات (QUD أو الـ Aligner)، ثم تدخل كمسودة.
5. إعدادات عامة: availability_mode، إظهار شارات مستوى التوقيت، عرض معاينة الصوت، النصوص الافتراضية للإسناد.
6. قواعد: لا ظهور عام دون published + voice confirmed + license permitted؛ كل تعديل مسجل في audit_logs؛ لا بيانات وهمية؛ تصميم الأدمن مطابق لتصميم الموقع الحالي.

## استئناف الدفعة2 — مواصفات K1–K9 الحرفية

1. مركز المراجعة (Review Center): صفحة موحدة لكل human_review_items مع تصنيف حسب النوع والأولوية، فلتر الحالة، عرض الأدلة (نتائج V1–V4، عينات صوتية، مقارنة جنبًا إلى جنب، روابط شروط المزوّد)، إجراءات فردية وجماعية (تأكيد/رفض/تأجيل مع ملاحظة)، وسجل قرارات. «لوحة جاهزية الإطلاق» في أعلاها: عدّاد البنود المعلّقة، القراء والتلاوات التي ستظهر، وما يمنع غيرها، وزر «افتح الـ flag» يعمل فقط عند استيفاء الشروط التي يحددها الأدمن (بتأكيد مزدوج وسجل).
2. قائمة القراء: صورة، الاسم، البلد، عدد التلاوات (عامة/الكل)، أفضل إتاحة، ملخص حالة الصوت، مميّز، ظاهر، ترتيب بالسحب؛ بحث وفلاتر (رواية، أسلوب، مصدر، إتاحة، حالة الصوت، حالة الترخيص، نوع المصدر) وإجراءات جماعية.
3. صفحة القارئ (تبويبات): (أ) الملف؛ (ب) التلاوات والمصادر: جدول لكل تلاوة بالاسم الوصفي القابل للتعديل (ع/إنجليزي)، المزوّد/القناة، الأسلوب، الرواية، السنة، الجودة، الإتاحة (مكتمل/شبه مكتمل/جزئي/غير متاح)، جودة التوقيت، حالة offset (v1/v2/فشل/غير متاح)، حالة الصوت (unverified/auto_verified/confirmed/mismatch) وأدلتها، حالة الترخيص، الحالة التقنية، مفتاح الظهور العام، الافتراضي، الترتيب بالسحب، الملاحظات؛ إجراءات: إخفاء/إظهار، جعلها افتراضية، نقلها لقارئ آخر (مع تدقيق)، فحص الروابط، إضافة رابط بديل؛ (ج) غرفة الاستماع: عينات لكل تلاوة تُشغَّل من رابط المزوّد بنطاق زمني أو عبر IFrame لليوتيوب، مقارنة جنبًا إلى جنب بين تلاوات القارئ نفسه، قائمة تحقق (الصوت يطابق القارئ؟ الأسلوب؟ الجودة؟ ضوضاء؟ تكرار؟)، تأكيد/عدم تطابق مع ملاحظة وسجل؛ (د) مصفوفة الإتاحة: 114 خلية ملوّنة لكل تلاوة (مكتمل، شبه مكتمل مع الكلمات الناقصة، جزئي بنطاقاته، غير متاح، بلا صوت)، وتفاصيل عند النقر ورابط لمحرر التوقيت؛ (هـ) الروابط والصحة: كل رابط، آخر فحص، الفشل، البدائل؛ (و) سجل التدقيق.
4. مصادر YouTube: تبويب لكل تلاوة YouTube يعرض القناة والفيديوهات/القوائم وحالة oEmbed، حقول rights_status والدليل، مشغّل IFrame مضمّن، ولوحة «ملفات الصوت المرخّصة»: رفع دفعة 114 ملفًا أو لصق روابط، تقدّم التحقق (ffprobe، SHA، offset)، حالة كل فصل (بحاجة ملف/قيد التحقق/جاهز)، وزر «اكتشاف مصدر لنفس التسجيل» (لصق رابط مرشح فيُفحص بالبصمة). لا يوجد أي زر تنزيل من YouTube.
5. صفحة المزوّدين: الحالة، ملخص الشروط، license_status، قائمة المضيفين المسموحة بالأدلة، صحة الروابط، حدود المعدل.
6. معالج «إضافة قارئ/تلاوة/مصدر» دون كود: اختيار نوع المحوّل (QUD Release، رابط ملف سورة، نمط روابط، EveryAyah/MP3Quran-like، Drive عام، YouTube: قناة/فيديو/قائمة تشغيل، ملف مرخّص)، بيانات الكتالوج، اختبار الروابط، استيراد التوقيتات (QUD أو الـ Aligner)، ثم تدخل كمسودة وتُضاف بنود المراجعة تلقائيًا.
7. إعدادات: availability_mode، voice_gate_policy، عرض شارات التوقيت، معاينة الصوت، نصوص الإسناد الافتراضية، محول التخزين (url_reference/s3_compatible).
8. القواعد: لا ظهور عام دون الشروط الأربعة؛ كل تعديل في audit_logs؛ لا بيانات وهمية؛ ما يتعذر يظهر معطّلًا بسبب واضح؛ تصميم الأدمن مطابق لتصميم الموقع.

### مركز التخزين — النص المعتمد

1. مركز التخزين في الأدمن (واجهته في A2): حالة المحول واختبار الاتصال، الاستخدام (GB وعدد الكائنات) لكل bucket ولكل تلاوة، قائمة الرفوعات (pending/failed/rejected) مع إعادة محاولة، تنبيه عند 70% من الطبقة المجانية وعند أي تقدير إنفاق >1$ شهريًا، وتكلفة تقديرية محسوبة من التسعير المسجَّل.
2. مهمة reconcile-storage (تُجدول أسبوعيًا): تكشف كائنات يتيمة في R2 غير مرتبطة بقاعدة البيانات وصفوف تشير لكائن مفقود، وتكتب تقريرًا فقط ولا تحذف شيئًا آليًا. الحذف الفعلي للكائنات soft_deleted إجراء أدمن بتأكيد مزدوج بعد 30 يومًا على الأقل.
3. نسخة مرجعية: manifest بالكائنات وsha256 يُصدَّر دوريًا (ملف بلا صوت) حتى يمكن التحقق من سلامة المحتوى.
