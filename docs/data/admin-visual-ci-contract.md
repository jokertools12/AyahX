# بوابة الأدمن البصرية في CI

`Admin visual strict` يشغّل MySQL 9.7.2 وRedis 7.2 داخل خدمات GitHub Actions مؤقتة، بمنافذ مربوطة بـ127.0.0.1. لا يصل إلى Railway، ولا يستخدم dump أو مفاتيح إنتاج أو استجابات API مصطنعة. كلمة مرور حساب الاختبار عشوائية وتبقى في ملف خاص خارج المستودع؛ لا تُرفع معه ملفات الدخول أو profile أو server.log.

## التحضير الحقيقي

`scripts/admin-visual-ci-server.ts` يرفض التشغيل دون `CI=true` و`AYAHX_ADMIN_VISUAL_CI=1`، ويرفض متغيرات اتصال قواعد خارجية، ثم يشترط schema فارغة باسم `ayahx_ci_admin_visual`. يطبق schema العامة، وصف الجداول القديمة الموثّق، وmigrations001–008 صراحة؛ لا يُعاد استخدام schema ممتلئة أو حذفها تلقائيًا. يقرأ ملفات النص القانوني والكتالوج من QUD Release v3.2.0 ويقارن SHA-256 قبل الاستيراد، ثم يثبت بصمة القانوني المعتمدة. يستعمل خدمات التطبيق وrouter الحقيقيين وRedis الفعلي، ولا يبدأ العمال أو أي ريندر.

بيانات الاختبار الموسومة `CI_VISUAL_ONLY` تشمل حسابًا مؤقتًا، وبنود صوت وترخيص واسم كلها pending، ورفعًا غير مكتمل. معرّفات فيديوهات YouTube مشتقة من روابط Release عبر parser الإنتاج؛ لا تنزيل أو استخراج أو API خاص بها. لا تُختلق موافقة صوت أو ترخيص أو offset.

يستورد seed حزمة `ahmed_saud_mp3quran.zip` الفعلية من Release v3.2.0 بعد تحقق SHA-256 للحزمة ولـmanifest المنشور، وبخدمات `readTimingPackage` و`prepareTimingRows` و`importTimingRecitation` نفسها. تُحسب أعداد التوقيتات وكلماتها وحالاتها وبصمة التخزين من المصدر؛ لا عدد ثابت في المستورد. تبقى التلاوة غير منشورة بلا إثبات offset مخترع. جرد مسار التوقيت يفتح آية جاهزة فعلية من هذه الحزمة عبر query state المعتاد، ويُظهر ربط النص القانوني المستورد.

فيديو أسود صامت مُولَّد محليًا لمدة ثانية، موسوم صراحة `CI_VISUAL_ONLY_SYNTHETIC_BLACK`، يملأ شكل المشغّل وحوار الحذف فقط. يقرأ ffprobe مدته وحجمه الفعليين، ويُخدم عبر endpoint الأدمن المحمي الحقيقي. يوجد داخل مسار `uploads/admin-visual-ci` المهمل في Git لأن خدمة الفيديو تتحقق من بقاء الملف داخل حد uploads؛ لا ملف فيديو أو مصادقة يدخل Git أو artifact العامة. ليس تلاوة أو ريندر D7 أو دليل جودة أو قبول M8، ولا يغيّر نشرًا أو حقوقًا. قبول المهام البشرية والتوقيت والفيديو الحقيقي على النسخة المستعادة والإنتاج يبقى بوابة مستقلة يديرها الجذر.

يُستعمل `--seed-only` للتحقق من التحضير دون تشغيل المنفذ3005. إعادة التشغيل تتطلب schema جديدة فارغة؛ لا يمحو السكربت التحضير السابق. يجب أن ينفذ الجذر هذا الأمر محليًا لأن كتابة قواعد الاختبار محصورة به.

## المصفوفة والإنفاذ

- جرد المسارات مشتق من AST لملف `AdminRoot.tsx`، ويُلزم كل الصفحات القديمة وصفحات الدفعة5. أي مسار ديناميكي جديد بلا معرّف معروف أو صفحة مطلوبة مفقودة يفشل، حتى لو كانت بقية الصفحات ناجحة.
- أحجام1366×768 و1536×864 و1920×1080 و390×844، وعربي/إنجليزي وفاتح/داكن، وتكبير Chromium فعلي100/125/150/200%. الـ200% فحص إضافي لقيد عمل الواجهة عند التكبير. امتداد MV3 يستعمل tabs.setZoom/getZoom مع إثبات devicePixelRatio؛ لا CSS scale أو تغيير حجم الخط لمحاكاة التكبير.
- يمرّر الوثيقة وكل حاوية تمرير رأسي ثم يشغل الماسح strict بالعتبات الأصلية، وaxe على الصفحة أو dialog النشط. المخالفات والحالات غير المحسومة تفشل؛ لا تعطيل لقواعد التباين أو تصغير للمصفوفة عند الفشل.
- فتح dialog مسموح فقط عبر trigger معلّم `data-admin-visual-open="slug"` يقابله محتوى `data-admin-visual-dialog="slug"`، ويُغلق بـEscape. مكوّن ConfirmDialog يتلقى `visualId="slug"` ثابتًا ويمرّره إلى المحتوى. جرد AST يفشل لأي محتوى غير معلّم أو opener مفقود أو معرّف مكرر؛ ثم يشترط التقرير تجربة ناجحة لكل حوار معلن. الحوار غير المتاح في البيانات المحضّرة لا يُحسب ناجحًا، ويتطلب تحضير fixture أو الوصول إلى التبويب المناسب دون تنفيذ الإجراء نفسه.
- الطلبات بعد الدخول للقراءة فقط؛ لا يسمح بالحفظ أو القرارات أو الرفع أو الريندر. تُسمح ملفات Google Fonts العامة عبر GET، وتُرفض الطلبات الخارجية الأخرى صراحة. لا يزعم الماسح فحص محتوى iframe عابر الأصل.
- يعاد ضبط حاويات الحد القرائي في Redis لحساب CI وحده بين الصفحات المستقلة، دون تغيير حارس الإنتاج أو استبداله. اختبار معدل الطلبات الحقيقي منفصل؛ النجاح البصري لا يثبت حدود المعدل.

الأدلة المرفوعة فقط: أرقام seed وبصماته العامة، وتقرير المسح وaxe بلا قيم inputs أو نصوص شخصية، وصور الفشل من بيانات CI العامة. نتائج القراءة المؤكدة للإنتاج ولقطات قبل/بعد وحذف QA الإنتاجي ليست من هذا job، وتبقى في تقرير الجذر.

## حالة التحقق في هذه الشريحة

نجحت اختبارات وحدات الماسح، واختبار tsx runtime، وجرد المسارات، وlint للملفات المعدّلة، وفحص TypeScript لنقطة التحضير. لم يُشغّل هذا الوكيل seed أو أي كتابة محلية/إنتاجية، ولم يشغّل CI عن بُعد. لا يُعلن نجاح القبول الحقيقي حتى ينفذه الجذر وتظهر نتيجته الفعلية.
